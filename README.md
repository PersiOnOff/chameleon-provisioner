# Chameleon Provisioner (v1.2.0)

[Read documentation in English](README_EN.md)

**Chameleon Provisioner** — контекстно-зависимый гибридный HID-провижинер для **Flipper Zero** с поддержкой проводного **USB HID** и беспроводного **Bluetooth LE HID** транспортов, динамической подменой USB-дескрипторов (`VID`, `PID`, `MFR`, `PROD`), эмуляцией мыши и независимостью от раскладки клавиатуры.

## Возможности (v1.2.0)

* **Два транспорта (`USB` и `BLE`):** Переключение между проводным USB HID и беспроводным Bluetooth LE HID долгим удержанием кнопки **OK**.
* **Изолированные ключи сопряжения BLE:** Хранит ключи Bluetooth HID отдельно в `/ext/apps_data/chameleon_provisioner/hid.keys`, не сбивая привязку Flipper к смартфону.
* **Динамическая подмена USB-дескрипторов:** Изменение `VID`, `PID`, производителя (`MFR`) и имени устройства (`PROD`) прямо из заголовка `.txt`-сценария (для режима USB).
* **Независимость от раскладки (`ALT_MODE 1`):** На Windows ASCII-команды вводятся через `Alt + Numpad`, исключая ошибки при активной русской раскладке.
* **Поддержка `.kl`-раскладок:** Загрузка стандартных таблиц маппинга из `/ext/badusb/assets/layouts/` (например, `LAYOUT ru-RU.kl`) для печати кириллицы.
* **Эмуляция мыши и скролла:** Плавные перемещения курсора, клики, двойные клики и прокрутка колесика.
* **Специальные клавиши (`KEY_*`):** Поддержка системных сочетаний (`KEY_ALT_Y`, `KEY_ALT_SHIFT`, `KEY_GUI_D`, `KEY_GUI_L` и др.) и навигации без мыши.
* **Проводник сценариев:** Выбор любого `.txt`-файла из `/ext/chameleon/` через системный браузер Flipper.

## Управление на Flipper Zero

| Кнопка | Действие |
| :--- | :--- |
| **Влево / Вправо** | Выбор целевой ОС (`Windows (PS)`, `Linux (Bash)`, `macOS (Zsh)`) |
| **Вверх / Вниз** | Открытие проводника для выбора `.txt`-сценария из `/ext/chameleon/` |
| **OK (короткое нажатие)** | Запуск выбранного сценария |
| **OK (долгое удержание)** | Переключение транспорта между `USB` и `BLE` |
| **Back** | Выход из приложения и восстановление штатного USB/BLE-профиля |

## Инструкция по сопряжению по Bluetooth HID (v1.2.0)

1. Запустите **Chameleon Provisioner** на Flipper Zero.
2. **Удерживайте кнопку OK** (около 1 секунды), пока индикатор в правом верхнем углу экрана не переключится с `USB` на **`BLE`**.
3. На целевом устройстве (ПК, ноутбуке, смартфоне Android или планшете iPad/iPhone) откройте **Настройки → Bluetooth**.
4. Найдите в списке доступных устройств **`Chameleon <Имя_Flipper>`** и выполните сопряжение.
5. После подключения индикатор на экране Flipper изменится на **`BLE*`** — теперь сценарии можно запускать по воздуху коротким нажатием **OK**.

> **Примечание:** В режиме `BLE` режим `ALT_MODE` (Alt+Numpad) автоматически отключается для совместимости с мобильными ОС и macOS/Linux, а тайминги нажатий адаптируются под пропускную способность Bluetooth.

## Синтаксис директив в `.txt`-сценариях

| Директива | Описание | Пример |
| :--- | :--- | :--- |
| `USB_ID <VID>:<PID>` | Подмена Vendor ID и Product ID (только USB) | `USB_ID 046D:C52B` |
| `MFR <строка>` | Подмена имени производителя (до 31 символа) | `MFR Apple Inc.` |
| `PROD <строка>` | Подмена названия устройства (до 31 символа) | `PROD Magic Keyboard` |
| `ALT_MODE <0\|1>` | Ввод ASCII через Alt+Numpad на Windows | `ALT_MODE 1` |
| `LAYOUT <файл.kl>` | Загрузка таблицы раскладки с SD-карты | `LAYOUT ru-RU.kl` |
| `NO_TERM` | Не открывать системный терминал автоматически | `NO_TERM` |
| `SLEEP <мс>` | Пауза выполнения в миллисекундах | `SLEEP 1500` |
| `MOUSE_MOVE <dx> <dy>` | Плавное смещение курсора мыши | `MOUSE_MOVE 120 -40` |
| `MOUSE_CLICK <btn>` | Клик мышью (`LEFT`, `RIGHT`, `MIDDLE`) | `MOUSE_CLICK LEFT` |
| `MOUSE_DBLCLICK` | Двойной клик левой кнопкой мыши | `MOUSE_DBLCLICK` |
| `MOUSE_SCROLL <delta>` | Прокрутка колесика (`+` вверх, `-` вниз) | `MOUSE_SCROLL -5` |
| `KEY_<имя>` | Нажатие спецклавиши или комбинации | `KEY_ALT_Y`, `KEY_GUI_L` |
