# Chameleon Provisioner for Flipper Zero

Контекстно-зависимый кроссплатформенный USB HID провижинер и BadUSB-движок для **Flipper Zero**, написанный на C с использованием официального инструментария `uFBT`.

Позволяет на лету подменять USB-дескрипторы (`VID`, `PID`, производителя и имя устройства), выполнять сценарии развертывания с SD-карты и безопасно вводить команды на Windows независимо от активной раскладки клавиатуры.

---

## Возможности

* **Динамический USB HID Spoofing:** подмена `VID`/`PID` (`USB_ID`) и строковых дескрипторов `Manufacturer` (`MFR`) / `Product` (`PROD`) прямо из заголовка текстового сценария без перекомпиляции `.fap`.
* **Независимый от раскладки ввод на Windows (`ALT_MODE`):** ввод ASCII-команд через удержание `Left Alt` + `Numpad` гарантирует корректную печать латиницы и спецсимволов даже при включенной русской или другой локальной раскладке.
* **Поддержка локальных раскладок (`.kl`):** чтение стандартных таблиц маппинга из `/ext/badusb/assets/layouts/` (например, `ru-RU.kl`, `en-US.kl`) для прямой печати UTF-8 текста.
* **Кроссплатформенность:** автоматическое открытие системного терминала под **Windows** (`PowerShell`), **Linux** (`Bash`) и **macOS** (`Terminal / Zsh`).
* **Имитация живого набора:** естественная рандомизация задержек между нажатиями клавиш.
* **Встроенный файловый браузер:** выбор любых `.txt` сценариев из директории `/ext/chameleon/` через стандартный `DialogsApp`.

---

## Управление на Flipper Zero

* **Влево / Вправо (`<` / `>`)** — выбор целевой ОС (`Windows (PS)`, `Linux (Bash)`, `macOS (Zsh)`).
* **Вверх / Вниз (`Up` / `Down`)** — открытие файлового менеджера для выбора `.txt` сценария из `/ext/chameleon/`.
* **OK** — парсинг заголовков, переключение USB в режим HID с подмененными дескрипторами, выполнение сценария и автоматический возврат исходного USB-режима.
* **Назад (`Back`)** — выход из приложения.

## Синтаксис сценариев (`.txt`)

Поместите свои сценарии в папку `SD Card/chameleon/`. При первом запуске приложение автоматически создаст директорию и базовый шаблон `win_ru_safe.txt`.

### Поддерживаемые директивы

| Директива | Пример | Описание |
| :--- | :--- | :--- |
| `USB_ID <VID>:<PID>` | `USB_ID 046D:C31C` | Задает 16-ричные идентификаторы производителя (`VID`) и устройства (`PID`) для USB HID. |
| `MFR <строка>` | `MFR Apple Inc.` | Подменяет строковый дескриптор производителя (`Manufacturer`, до 31 символа). |
| `PROD <строка>` | `PROD Magic Keyboard` | Подменяет строковый дескриптор названия устройства (`Product`, до 31 символа). |
| `ALT_MODE <0\|1>` | `ALT_MODE 1` | Включает (`1`) или выключает (`0`) ввод ASCII через `Alt + Numpad` на Windows. |
| `LAYOUT <файл.kl>` | `LAYOUT ru-RU.kl` | Загружает таблицу раскладки из `/ext/badusb/assets/layouts/` для печати UTF-8 символов. |
| `SLEEP <мс>` | `SLEEP 1500` | Пауза выполнения сценария в миллисекундах. |
| `#` или `REM ` | `# Комментарий` | Строка-комментарий (игнорируется при выполнении). |

*(Любая другая непустая строка впечатывается в открытый терминал и завершается нажатием `Enter`).*

## Примеры сценариев

### 1. Windows: независимый от раскладки запуск с подменой под Logitech
```text
# Безопасный запуск при любой раскладке клавиатуры Windows
USB_ID 046D:C31C
MFR Logitech
PROD USB Keyboard
ALT_MODE 1
Write-Host 'Chameleon Provisioner Ready!' -ForegroundColor Green
Get-ComputerInfo | Select-Object CsName, OsName
```

### 2. macOS / Linux: маскировка под Apple Magic Keyboard
```text
USB_ID 05AC:024F
MFR Apple Inc.
PROD Magic Keyboard
echo '=== Provisioning Started ==='
uname -a && ip -br a
```

### 3. Смешанный режим (латинские команды + кириллица на Windows)
```text
USB_ID 046D:C52B
MFR Logitech
PROD USB Receiver
ALT_MODE 1
notepad.exe
SLEEP 1000
LAYOUT ru-RU.kl
ALT_MODE 0
Привет от Flipper Zero!
```

## Сборка из исходников (`uFBT`)

1. Установите `uFBT`:
   ```bash
   python -m pip install --upgrade ufbt
   ```
2. Подключите Flipper Zero по USB (закройте `qFlipper`, чтобы освободить COM-порт) и выполните:
   ```bash
   ufbt launch
   ```
   Скомпилированный `.fap`-файл появится в меню **Apps → USB → Chameleon Provisioner**.
